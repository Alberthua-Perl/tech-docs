# 人形机器人产业链上游核心零部件深度研究

> 研究时间：2026年10月 | 覆盖范围：精密减速器、丝杠、电机、传感器、灵巧手、执行器总成

---

## 一、产业链总览与价值分布

### 1.1 产业链架构

人形机器人产业链可清晰划分为**上游核心零部件 → 中游整机集成 → 下游场景应用**三大环节。

- **上游零部件**占整机BOM成本约**70%**（部分机构测算超85%），中游本体制造约20%，下游集成与软件约10%。
- 上游核心零部件体系可划分为四大板块：
  - **精密传动部件**（关节减速器、滚柱丝杠、精密轴承）→ "骨骼"
  - **动力执行部件**（无框力矩电机、微型伺服、执行器总成）→ "肌肉"
  - **感知传感器部件**（六维力传感器、视觉传感器、姿态传感器）→ "神经"
  - **轻量化结构部件**（PEEK材料、精密结构件、轻量化壳体）

线性执行器、旋转执行器与灵巧手三大执行器合计占整机BOM约73%，核心构成单元为丝杠、无框力矩电机、减速器、力传感器、空心杯电机及轴承。

> 来源：乐晴智库精选《人形机器人四大核心零部件全解析》（2026年6月）；人形机器人产业链上游零部件龙头全景解析（2026年7月）

### 1.2 各零部件价值量占比（整机BOM成本）

根据东海证券深度报告及各机构测算，主要零部件在整机BOM成本中的占比如下：

| 零部件 | BOM占比 | 备注 |
|:---|:---:|:---|
| 行星滚柱丝杠 | **~19%** | 价值量第一，国产替代空间最大 |
| 无框力矩电机 | **~16%** | 旋转+线性关节核心动力 |
| 减速器（谐波+行星+RV） | **~13%** | 谐波用量最大（单台14-20个） |
| 力矩传感器 | **~11%** | 含六维力+一维力矩 |
| 空心杯电机 | **~8%** | 灵巧手核心驱动 |
| IMU | ~2% | 惯性测量单元 |
| 其他（结构件/电池/热管理/软件等） | ~31% | — |

精密传动与动力执行部件合计占上游价值超60%，是产业链核心价值高地；感知传感器、轻量化结构件分别占比约20%、15%。

> 来源：东海证券《人形机器人从概念到量产，核心零部件机遇梳理》（2025年7月）；财信证券人形机器人行业2026年度策略（2026年1月）

## 二、精密减速器赛道

### 2.1 技术壁垒与分类对比

减速器是旋转关节的核心传动部件，主要功能是降低电机转速、放大扭矩、保证定位精度。三大类型对比：

| 指标 | 谐波减速器 | 行星减速器 | RV减速器 |
|:---|:---|:---|:---|
| 结构 | 柔轮+刚轮+波发生器 | 太阳轮+行星轮+内齿圈 | 摆线针轮两级传动 |
| 传动精度 | ≤60角秒 | ≤180角秒 | ≤60角秒 |
| 传动比 | 30-160 | 3-512 | 30-192.4 |
| 额定转矩 | 6.6-921 N·m | 40-1200 N·m | 101-6135 N·m |
| 设计寿命 | >8,000h | >20,000h | >6,000h |
| 价格区间 | 1000-1500元 | 300-500元 | 3000-5000元 |
| 应用关节 | 小臂/腕部/手部 | 下肢/低成本关节 | 大臂/机座重载 |

**核心壁垒**：
- **谐波减速器**：柔轮反复形变，对材料疲劳寿命、齿形设计、热处理工艺要求极高。柔轮强度、弹性模量和化学成分配比是核心难点，国内在材料研发与质量控制方面积累不足，易导致柔轮疲劳断裂。
- **RV减速器**：零件数量多、加工精度要求高，多组摆线轮加工一致性是核心难点。
- **行星减速器**：结构相对简单，但人形机器人场景下的微型化、多级传动定制需求推高制造难度。

> 来源：西部证券《人形机器人大势所趋》（2026年5月）；华创证券"人形机器人的Optimus时刻"系列（十一）（2025年7月）；财达证券减速器系列研究（2026年7月）

### 2.2 国产化率现状（2025-2026年）

**整体格局**：2024年内资企业在中国精密减速器市场销量占比已达**70%**，但营收占比仅为**57%**，反映国产产品在一致性与稳定性方面仍与外资存在差距。国产减速器多应用于中低端场景，单价较低；高端应用领域仍以外资品牌为主导。

**分品类国产化率**：

| 品类 | 国产化率 | 竞争格局 |
|:---|:---|:---|
| 谐波减速器 | **内资市占率81.5%**（2024年销量口径），国产化率突破60% | 绿的谐波市占率24.8%（国内第一），来福谐波紧随其后；哈默纳科仍主导高端市场 |
| RV减速器 | 环动科技市占率约**25%**（2024年），逐年上升（2021年仅10.11%） | 纳博特斯克仍居第一；环动科技（双环传动子公司）为国产龙头 |
| 行星减速器 | 相对较高 | 科峰智能等企业发力 |

**2026年最新进展**：上游零部件国产化率已从此前不足15%提升至**38.6%**，但高端核心部件仍存在明显卡脖子短板。中端零部件全面放量、高端零部件加速攻坚。

> 来源：MIR睿工业《2025年中国精密减速器行业发展白皮书》；华创证券（2025年7月）；人形机器人产业链上游零部件龙头全景解析（2026年7月）

### 2.3 国内外代表企业

**国际巨头**：
- **哈默纳科（Harmonic Drive）**：谐波减速器全球龙头，S齿形与IH齿形专利壁垒，2026年扩产至347万台
- **纳博特斯克（Nabtesco）**：RV减速器全球龙头

**国内核心企业**：

| 企业 | 赛道 | 核心优势与进展 |
|:---|:---|:---|
| **绿的谐波** | 谐波减速器 | 国内龙头，市占率24.8%第一；自主研发P型齿形，全球第二套自主方案；灵巧手微型谐波外径最小6mm；产能2025年底约79万台，在建项目新增100万台；**唯一通过特斯拉全流程量产认证的谐波减速器厂商** |

| **来福谐波** | 谐波减速器 | 以δ齿形实现应力优化，定位精度中国第二、全球第三；滚齿及自研车齿工艺将加工时长压缩85% |
| **科峰智能** | 行星减速器 | 聚焦精密行星减速器，拓展机器人核心部件 |

> 来源：华鑫证券精密减速器深度报告（2026年9月）；东吴证券谐波减速器深度研究系列八（2025年5月）；华创证券（2025年7月）

## 三、丝杠赛道

### 3.1 技术路线与壁垒

丝杠是将旋转运动转化为直线运动的核心传动部件，主要分为：

| 类型 | 特点 | 人形机器人应用 |
|:---|:---|:---|
| **行星滚柱丝杠** | 承载力是滚珠丝杠5-10倍，寿命长体积小，滚动摩擦 | **大腿/大臂等线性关节（主力方案）**，单台Optimus用量约14根（线性关节）+部分旋转关节，总计约20-28根 |
| **滚珠丝杠** | 低成本、高精度（C3-C5级）、技术成熟 | 灵巧手、小臂等轻载定位关节 |
| 梯形丝杠 | 滑动摩擦，结构简单成本低 | 低端场景 |

**核心壁垒**：
- 精度要求达C3-C5级（导程累积误差控制在微米级）
- 内螺纹精密磨削工艺、钢材金相组织稳定性
- 大批量生产下的批次一致性是主要考验
- 国产厂商大多可完成样品试制，但C0-C2超高精度量产良率仍与海外龙头存在差距

**"卡脖子"程度**：丝杠是国产化率最低的核心零部件之一。全球市场长期由欧洲企业主导，2023年Rollvis（瑞士）和GSA（瑞士）在中国滚柱丝杠领域合计占比近**60%**，南京工艺、济宁博特分别仅约6%和5%。

> 来源：长城证券《丝杠，机器人的肌肉》（2026年10月）；中信建投丝杠产业链报告（2025年3月）；东吴证券丝杠深度报告（2025年6月）

### 3.2 国产突破进展（2025-2026年）

行星滚柱丝杠被认为是人形机器人零部件中**价值量最高、壁垒最深、国产替代空间最大**的环节。

| 企业 | 核心进展 |
|:---|:---|
| **五洲新春** | 国内行星滚柱丝杠**绝对龙头**；反向式设计适配机器人紧凑空间，精度达C3级，定位误差≤5μm，动态寿命≥2万小时；**已通过特斯拉全认证**，锁定Optimus 70%线性关节丝杠份额；2025Q4起批量稳定供货；2026下半年新增40万套产能；还突破1.8mm微型滚珠丝杠（适配灵巧手） |
| **新剑传动** | 特斯拉Optimus**一级供应商**，行星滚柱丝杠产品2022年起已应用于Optimus；正在冲刺IPO |
| **北特科技** | 灵巧手微型丝杠精度达C5级；与优必选、智元机器人等深度合作；已进入特斯拉产业链；昆山基地2026年量产，合计340万套年产能 |
| **恒立液压** | 液压件龙头跨界；集成式滚珠丝杠电动缸已进入特斯拉供应链小批量出货；全部丝杠产品线年产值可超30亿元 |
| **双林股份** | 自研反向式行星滚柱丝杠，自主掌控核心螺纹磨床设备；已进入特斯拉Optimus二级供应链 |
| **鼎智科技** | 全系列有刷和无刷空心杯电机、精密齿轮箱、滚珠丝杠和行星滚珠丝杠布局；产品已送样 |

**市场空间**：若特斯拉Optimus产量达到100万台，仅特斯拉一家丝杠市场空间可达**140亿元**（单根1000元假设）；若考虑灵巧手微型丝杠，2030年全球人形机器人丝杠市场规模可达**267.9亿元**（华经情报网预测），乐观预测超450亿元。

> 来源：五洲新春定增公告（2025年12月）；人形机器人概念滚珠丝杠龙头研发实力大比拼（2026年8月）；甬兴证券丝杠国产化报告（2025年10月）；申万宏源机器人行业点评（2025年4月）

## 四、电机赛道

### 4.1 无框力矩电机

- **应用**：旋转执行器（14个）和线性执行器（14个）的核心动力源，单台Optimus用量约28个
- **技术壁垒**：高功率密度、高扭矩密度、散热设计
- **国产化率**：国内在减速器、电机领域已具备替代能力（乐晴智库，2026年6月）
- **代表企业**：汇川技术、步科股份、昊志机电、拓邦股份

### 4.2 空心杯电机

- **应用**：灵巧手核心驱动，单台Optimus灵巧手用量12-34个（随代际升级增加）
- **技术壁垒**：无铁芯转子结构消除齿槽转矩，机械时间常数<10ms，能量转换效率>85%；极限制造能力决定灵巧手能否在"指尖级"空间输出足够动力
- **全球竞争格局**：Maxon（瑞士）、Faulhaber（德国）、Portescap（瑞士）三家合计市占率**70-80%**，稳居第一梯队
- **国产突破**：

| 企业 | 进展 |
|:---|:---|
| **鸣志电器** | 国内空心杯电机龙头；高精度步进电机全球市占率前三；**已通过特斯拉C轮认证**，成为特斯拉空心杯电机准供应商；成本仅为瑞士Maxon的1/8 |
| **鼎智科技** | 国内首家实现空心杯电机自动化批产企业；自研制造设备保障一致性；已向军工及医疗领域渗透 |
| **兆威机电** | 自研三款灵巧手电机：两极/四级转子无刷空心杯电机，功率密度>0.5瓦/克，最小尺寸6mm |
| **拓邦股份** | 覆盖7mm-40mm外径全系列空心杯电机；已向超10家龙头企业送样 |

> 来源：广发证券灵巧手深度报告（2025年4月）；华创证券灵巧手产业链解析（2026年3月）；国泰海通灵巧手专题（2025年7月）

## 五、传感器赛道

### 5.1 六维力/力矩传感器

**产品定义**：同时测量X/Y/Z三个方向力（Fx,Fy,Fz）和绕三轴力矩（Mx,My,Mz），是力传感器领域的"金字塔顶端"产品。技术难度呈指数级上升——"一维力传感器难度的六次方"。

**核心壁垒**：
- 结构解耦、算法解耦、标定工艺、信号处理的复杂耦合
- 六维联合加载标定的复杂性
- 多通道信号的温漂、蠕变、交叉干扰、数据处理的实时性
- 超50%成本来自应变片和人工加工成本

**产品单价**：目前2-4万元/个，随人形机器人放量有望降至5000元以内。

**"卡脖子"程度**：国产替代正在进行中，是除丝杠外最核心的卡脖子环节。

**市场格局与国产突破**：

| 企业 | 进展与份额 |
|:---|:---|
| **蓝点触控** | 2024年人形机器人六维力传感器出货量占比约**62%**，预计2025年超70%（内资第一） |
| **坤维科技** | 占比**25.7%**，已获银河通用、北京人形机器人创新中心大批量订单 |
| **宇立仪器** | 占比**6.9%**；2025年发布全球最小6mm直径六维传感器 |
| **柯力传感** | 国内传感器龙头，连续14年力学传感器国内市占率第一；六维力传感器线性精度达0.1%FS，打破国际垄断；已完成手腕/脚腕/工业臂产品系列开发；已向超50家企业送样，2025H1出货近千套；积极推进MEMS硅基六维力传感器研发 |
| **昊志机电** | 六维力传感器已应用于按摩机器人并批量销售 |
| **安培龙** | 金属应变式六维力传感器已完成开发，正在送样 |

**市场预测**：2025年中国六维力传感器人形机器人领域出货量预计达1.23万台（同比+510%）；2030年全球人形机器人力传感器市场规模预计达**328亿元**（GGII预测），其中六维力传感器138亿元。

> 来源：GGII《2025中国人形机器人六维力传感器市场分析报告》；国联民生传感器深度报告（2026年4月）；平安证券感知系统专题（2025年3月）；时代商业研究院（2025年8月）

### 5.2 视觉传感器

- **代表企业**：奥比中光（3D视觉感知技术）
- **应用**：机器人环境感知、物体识别、空间定位
- 3D视觉感知技术可让机器人获得更准确的外部环境信息，降低误差

### 5.3 电子皮肤/触觉传感器

- 尚处产业化早期，柔性阵列式、磁/霍尔阵列式、光学视触觉多路径并行
- 海外厂商主导，国内帕西尼感知、汉威科技（苏州能斯达）等积极布局
- 汉威科技电子皮肤方案覆盖12个触觉点，已通过特斯拉实验室测试并进入B样验证阶段

## 六、灵巧手赛道

### 6.1 技术概况

灵巧手是人形机器人的末端执行器，占整机成本约**14%**。核心硬件模块包括驱动系统、传动系统及感知系统。

**核心零部件价值分布（产业化成熟阶段）**：
- 空心杯电机+齿轮组：约**50%**
- 触觉传感器：超**25%**

**发展趋势**：自由度从11个→22个（特斯拉Gen3），驱动端电机数量翻倍以上，传动端丝杠有望替代蜗杆。

### 6.2 代表企业

| 企业 | 产品与进展 |
|:---|:---|
| **兆威机电** | 国内灵巧手标杆企业；最新DM17（17主动自由度）、B20（20自由度，重量仅600g）；核心部件全栈自研（电机+传动+控制）；苏州规划产能10万套/年；已与特斯拉、华为、优必选、宇树等合作；2026年3月港股上市 |
| **鸣志电器** | 灵巧手空心杯电机主力供应商，单台Optimus用量16-17个 |

## 九、总结与展望

### 9.1 国产化进度总表（2026年）

| 零部件 | 国产化率 | 卡脖子程度 | 2026年关键进展 |
|:---|:---:|:---:|:---|
| 谐波减速器 | ★★★★ 超60% | 低 | 绿的谐波扩产至150万台，已通过特斯拉全认证 |
| RV减速器 | ★★★ ~25% | 中 | 环动科技市占率逐年上升，进入特斯拉验证 |
| 行星滚柱丝杠 | ★★ 不足20% | **极高** | 五洲新春通过特斯拉全认证锁定70%份额 |
| 无框力矩电机 | ★★★★ 较高 | 低 | 已具备替代能力 |
| 空心杯电机 | ★★★ 中 | 中高 | 鸣志电器通过特斯拉C轮认证 |
| 六维力传感器 | ★★★ 中 | **高** | 内资主导格局形成，柯力传感等出货放量 |
| 灵巧手 | ★★★★ 较高 | 中 | 兆威机电17/20自由度产品全球领先 |

### 9.2 核心投资主线

1. **丝杠环节**：价值量最高（19%）、壁垒最深、国产替代空间最大，是产业链最核心配置方向
2. **减速器环节**：谐波国产化已成熟，RV仍在追赶；绿的谐波作为特斯拉链核心标的确定性最强
3. **传感器环节**：六维力传感器随人形机器人放量需求激增（2025年出货量+510%），国内已形成以内资为主导的格局
4. **灵巧手环节**：自由度翻倍（11→22）带来电机、丝杠、传感器用量翻倍以上增长

### 9.3 风险因素

- 人形机器人量产进度不及预期
- 特斯拉核心部件自研战略压缩供应商份额
- 行业同质化竞争加剧导致价格下行
- 核心零部件国产化替代不及预期
- 技术迭代与工程化不及预期
